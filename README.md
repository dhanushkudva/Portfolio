## Highlights

- **Terminal boot loader** that wipes into the hero ("ACCESS GRANTED")
- **Mouse tracking:** custom cursor with a lagging ring, spotlight reveal, magnetic buttons, 3D tilt cards, and a reactive particle shield in the hero
- **Scroll animation:** smooth scrolling, pinned sections, a self-drawing experience timeline, and a horizontal-scroll Credentials Vault
- **Credentials Vault:** certificate previews with lightbox and verification links
- **Easter eggs:** press `~` for a working mini terminal (`help`, `about`, `skills`, `certs`, `ctf`, `contact`, `whoami`), plus a Konami-code glitch effect
- **Accessible and fast:** WCAG AA contrast, keyboard navigation, reduced-motion support, responsive down to mobile, SEO-ready

## Getting started

```bash
# clone the repository
git clone https://github.com/dhanushkudva/<your-repo-name>.git
cd <your-repo-name>

# install dependencies
npm install

# start the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

```bash
# production build
npm run build
npm start
```

## Project structure

```
.
├── app/            # Next.js routes and layout
├── components/     # UI sections, cursor, 3D scene, terminal
├── public/
│   └── certs/      # Certificate previews and downloadable files
├── styles/         # Global styles and design tokens
└── README.md
```

## Customising

- **Accent color:** change the CSS variable in the global styles (default is crimson)
- **Content:** update the data files for experience, credentials and skills
- **Certificates:** add files to `public/certs/` and register them in the credentials data

## Deployment

Deploy in one click with [Vercel](https://vercel.com), or run `npm run build` and host the output anywhere that supports Next.js.
